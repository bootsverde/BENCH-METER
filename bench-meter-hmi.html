Project setup

New project

  1. C-more Programming Software → New Project → panel EA7-T8C.
  2. Panel Manager: protocol AutomationDirect CLICK on the serial port. 38400 baud, odd parity, 8 data bits, 1 stop bit, PLC address 1, RS-232.
  3. Screen 1 = Meter, and make it the start-up screen. Screen 2 = Setup.
  4. Set the screen saver to dim rather than off, or turn it off, so a bench reading never disappears mid-test.
  5. Transfer the project over USB, then connect the EA-2CBL to CLICK Port 2. Port 1 stays free for the programming cable.

Tag database

  • Floating PT 32: DF1–DF4, DF20, DF30, DF32, DF33
  • Signed Int 16: DS1
  • Discrete: C1–C3, C5–C8, C13, C14, C20, C21, C44, C51–C53
  • Use the ladder nicknames as the tag names (MODE, DISPLAY, HOLD_ON…), so the panel and PLC programs read the same.
  • If a Numeric Display shows odd huge numbers, the tag was probably made as an integer. Change it to Floating PT 32.
