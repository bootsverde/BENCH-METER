CLICK Programming Software · C0-02DD2-D + C0-4AD2DA-2 · Rev A

Bench Meter Ladder

The complete ladder program for the bench meter: scaling, overload and fault flags, 100 ms averaging, mode select, HOLD, REL (zero), MIN/MAX and the continuity beeper, plus the analog module setup and the C-more tags that go with it. Enter it rung by rung in the CLICK software.

1 · Analog module setup

In CLICK software, open Setup → System Configuration, select the C0-4AD2DA-2 (slot 1), and open its setup:

  • Inputs CH1–CH4: enabled, 0–10 V, scaled to engineering units 0.000 → 10.000, stored in DF1–DF4. Every value in the ladder is then in volts at the terminal.
  • Output CH1: from DF5, scaled 0.000 → 10.000 = 0–10 V. Output CH2: disabled.
  • If the software assigns different DF addresses, keep its choice and swap those addresses into the ladder.
  • The C0-02DD2-D's own analog (AD1/AD2, DA1/DA2) is not used. It's only 0–5 V or 4–20 mA at 12-bit, so all measuring stays on the C0-4AD2DA-2. Check Setup → CPU Built-in I/O Setup to see which registers the built-in channels took, so you don't mix them up with the module's DF1–DF5.
  • Setup → Com Port Setup: Port 2 = Modbus RTU, node 1, 38400, 8-O-1 for the panel. Leave Port 1 at its defaults for programming.
  • Setup → Memory Setup: make sure DF20 (the DC calibration factor) is in the retentive range, so it survives a power cycle.

3 · Program

Order matters. Enter the rungs in this order. The toggles, mode-change pulse and REL capture depend on the earlier rungs running first in the same scan. CLICK adds its own END rung after the last one.

4 · C-more EA7-T8C tags

Panel setup

  • PLC protocol: AutomationDirect CLICK, serial, 38400 baud, odd parity, 8 data bits, 1 stop bit, node 1. Set CLICK Port 2 (Setup → Com Port Setup) to Modbus RTU with the same settings.
  • Tags: create them with the CLICK addresses exactly as shown. Use data type Floating PT 32 for DF, Signed Int 16 for DS, and Discrete for C.
  • Reading display: make three numeric displays tied to DF30, stacked in the same spot. Give AC V 1 decimal, DC V 3 decimals, and Ω 1 decimal, and set each one's visibility from C51, C52 or C53.
  • OL overlay: put a red "OL" text object on top, visible when C44 is on.
  • Trend graph: plot DF30, sampling every 0.5 s over 60 s.

5 · First run

  1. Program through Port 1. The panel stays connected on Port 2 the whole time. Put the CPU in RUN.
  2. Open a Data View on DF1–DF5. You should see DF4 ≈ 10.0 and DF1 ≈ 1.00 (4 mA, 0 VAC), and C14 off.
  3. DC mode: put a known 24 V on the DC jacks. If DF30 is off from your reference meter, set DF20 = 24.00 ÷ DF2.
  4. Ω mode, leads shorted: press REL. It should read 0.0 and the beeper sounds. Put a 1 kΩ resistor on the leads and check it reads about 1000.
  5. AC mode: check against your handheld on 120 V first, then 480 V.
